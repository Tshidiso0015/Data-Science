Customer Churn Analysis

Project Overview

This project analyses customer churn in a telecommunications company to identify patterns and factors associated with customers leaving the service. The objective was to use data analysis to understand customer behaviour and identify areas where customer retention strategies could be improved.

Tools and Technologies

Python

Pandas and NumPy

Data visualisation libraries

Google Colab

Methodology

The project involved data inspection, cleaning, exploratory data analysis (EDA), and visualisation. Customer characteristics, contract types, and billing information were examined to identify patterns associated with churn.

Key Findings

The analysis identified higher churn among senior citizens and customers on month-to-month contracts. It also explored the relationship between customer charges and churn behaviour.

Skills Demonstrated

Data cleaning, exploratory data analysis, Python programming, data visualisation, and translating analytical findings into business insights.
